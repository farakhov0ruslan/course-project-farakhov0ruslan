# ADR-004 — Secure File Handling for Imports

**Status:** Accepted
**Date:** 2025-11-09

## Context
Импорт заметок и тегов позволяет пользователю загружать файлы (CSV/JSON). Без проверок это создаёт риск DoS, загрузки вредоносных бинарей или симлинков на хост-файлы контейнера.

## Decision
Добавлен модуль `utils_library/file_security.py`, который:
- ограничивает размер файлов (`MAX_FILE_SIZE=2 MiB`);
- определяет MIME-тип по содержимому (`python-magic`);
- разрешает только `text/csv`, `application/json`;
- при несоответствии MIME возвращает **415**;
- при превышении лимита размера возвращает **413**;
- полностью отказывается от записи на диск → используются временные буферы `BytesIO`.

## Consequences
Импорт теперь безопасен против:
- загрузки произвольных бинарей;
- path traversal / симлинков;
- DoS чрезмерным объёмом входных данных.
